3. Ordinary Least Squares (OLS)

Unpenalized SVD least squares (numpy.linalg.lstsq) on \(\tilde{\mathbf{X}}_{\mathrm{aug}} = [\mathbf{1}, \tilde{\mathbf{X}}]\).

$$\min_{\boldsymbol{\beta} \in \mathbb{R}^{k}} \|\mathbf{y} - \tilde{\mathbf{X}}_{\mathrm{aug}}\boldsymbol{\beta}\|_2^2 = \mathbf{e}^\top\mathbf{e}, \quad k = p + 1$$
(1)
$$(\tilde{\mathbf{X}}_{\mathrm{aug}}^\top \tilde{\mathbf{X}}_{\mathrm{aug}})\hat{\boldsymbol{\beta}} = \tilde{\mathbf{X}}_{\mathrm{aug}}^\top \mathbf{y} \implies \tilde{\mathbf{X}}_{\mathrm{aug}}^\top \mathbf{e} = \mathbf{0}$$
(2)

\(\mathbf{e} = \mathbf{y} - \tilde{\mathbf{X}}_{\mathrm{aug}}\hat{\boldsymbol{\beta}}\). If \(\operatorname{rank}(\tilde{\mathbf{X}}_{\mathrm{aug}}) \lt k\), SVD yields \(\hat{\boldsymbol{\beta}} = \tilde{\mathbf{X}}_{\mathrm{aug}}^{+}\mathbf{y}\).

Matrix Derivation: Hat Matrix \(\mathbf{H}\), \(\mathbf{M}\) & Gauss-Markov
$$\mathbf{H} = \tilde{\mathbf{X}}_{\mathrm{aug}}(\tilde{\mathbf{X}}_{\mathrm{aug}}^\top\tilde{\mathbf{X}}_{\mathrm{aug}})^{-1}\tilde{\mathbf{X}}_{\mathrm{aug}}^\top, \quad \mathbf{M} = \mathbf{I}_n - \mathbf{H}$$
$$\hat{\mathbf{y}} = \mathbf{H}\mathbf{y}, \quad \mathbf{e} = \mathbf{M}\mathbf{y}, \quad \operatorname{Var}(\hat{\boldsymbol{\beta}}) = \sigma^2(\tilde{\mathbf{X}}_{\mathrm{aug}}^\top\tilde{\mathbf{X}}_{\mathrm{aug}})^{-1}$$

Under \(\mathbb{E}[\boldsymbol{\varepsilon}\mid \tilde{\mathbf{X}}_{\mathrm{aug}}] = \mathbf{0}\), \(\mathbb{E}[\boldsymbol{\varepsilon}\boldsymbol{\varepsilon}^\top \mid \tilde{\mathbf{X}}_{\mathrm{aug}}] = \sigma^2 \mathbf{I}_n\), OLS is BLUE (\(\hat{\sigma}^2 = \frac{\mathbf{e}^\top\mathbf{e}}{n - k}\)). Heteroskedasticity requires White’s sandwich covariance.

Orthogonal Projection
ŷ = H y ∈ col(X̃_aug) e = M y ⊥ col(X̃_aug)

4. Ridge Regression (\(\ell_2\))

Smooth \(\ell_2\) shrinkage on standardized slopes (unpenalized \(\beta_0\)); retains all \(p\) predictors.

$$\min_{\beta_0 \in \mathbb{R},\, \boldsymbol{\beta} \in \mathbb{R}^p} \|\mathbf{y} - \beta_0\mathbf{1} - \tilde{\mathbf{X}}\boldsymbol{\beta}\|_2^2 + \alpha\|\boldsymbol{\beta}\|_2^2 \quad (\lambda \equiv \alpha \ge 0)$$
(3)
$$\hat{\boldsymbol{\beta}}_\alpha = (\tilde{\mathbf{X}}^\top\tilde{\mathbf{X}} + \alpha \mathbf{I}_p)^{-1}\tilde{\mathbf{X}}^\top\tilde{\mathbf{y}}, \quad \kappa(\tilde{\mathbf{X}}^\top\tilde{\mathbf{X}} + \alpha\mathbf{I}_p) = \frac{d_1^2 + \alpha}{d_p^2 + \alpha}$$
(4)

\(\tilde{\mathbf{y}} = \mathbf{y} - \bar{y}\mathbf{1}\), \(\hat{\beta}_0 = \bar{y}\), singular values \(d_1 \ge \dots \ge d_p \ge 0\). sklearn.Ridge omits \(\frac{1}{2n}\).

SVD Shrinkage & Effective Degrees of Freedom
$$\hat{\boldsymbol{\beta}}_\alpha = \sum_{d_j \gt 0} \mathbf{v}_j \frac{d_j}{d_j^2 + \alpha}\mathbf{u}_j^\top\tilde{\mathbf{y}}, \quad \operatorname{df}(\alpha) = \sum_{j=1}^p \frac{d_j^2}{d_j^2 + \alpha}$$
$$\operatorname{Var}(\hat{\boldsymbol{\beta}}_\alpha) = \sigma^2\sum_{j=1}^p \frac{d_j^2}{(d_j^2+\alpha)^2}\mathbf{v}_j\mathbf{v}_j^\top \preceq \sigma^2(\tilde{\mathbf{X}}^\top\tilde{\mathbf{X}})^{-1}$$

Unstandardized recovery: \(\hat{\beta}_{\mathrm{unstd}, j} = \hat{\beta}_{\alpha, j} / s_j\), \(\hat{\beta}_{0,\mathrm{unstd}} = \bar{y} - \sum_{j=1}^p \hat{\beta}_{\mathrm{unstd}, j}\bar{x}_j\).

5. Lasso Regression (\(\ell_1\))

Convex \(\ell_1\) penalty yielding continuous shrinkage and exact sparsity via coordinate-wise soft-thresholding.

$$\min_{\beta_0 \in \mathbb{R},\, \boldsymbol{\beta} \in \mathbb{R}^p} \frac{1}{2n}\|\mathbf{y} - \beta_0\mathbf{1} - \tilde{\mathbf{X}}\boldsymbol{\beta}\|_2^2 + \alpha\|\boldsymbol{\beta}\|_1 \quad (\lambda \equiv \alpha \ge 0)$$
(5)
$$\hat{\beta}_j = \frac{1}{g_j}\mathcal{S}\!\left(\frac{1}{n}\tilde{\mathbf{x}}_j^\top \mathbf{r}^{(-j)},\, \alpha\right), \quad \alpha_{\max} = \frac{1}{n}\|\tilde{\mathbf{X}}^\top\tilde{\mathbf{y}}\|_\infty$$
(6)

\(g_j = \frac{1}{n}\|\tilde{\mathbf{x}}_j\|_2^2 = 1\), \(\mathcal{S}(z, \alpha) = \operatorname{sign}(z)\max(|z| - \alpha, 0)\), \(\mathbf{r}^{(-j)} = \tilde{\mathbf{y}} - \sum_{k \ne j}\tilde{\mathbf{x}}_k \hat{\beta}_k\).

KKT Optimality & Active Set \(|A(\alpha)|\)
$$\frac{1}{n}\tilde{\mathbf{X}}^\top(\tilde{\mathbf{y}} - \tilde{\mathbf{X}}\hat{\boldsymbol{\beta}}) = \alpha \hat{\mathbf{s}}, \quad \hat{s}_j \in \partial|\hat{\beta}_j|$$
(7)
$$\left|\frac{1}{n}\tilde{\mathbf{x}}_j^\top \hat{\mathbf{r}}\right| = \alpha \ (\hat{\beta}_j \ne 0), \quad \le \alpha \ (\hat{\beta}_j = 0), \quad \operatorname{df}(\alpha) = |A(\alpha)|$$

Under collinearity, correlated predictors can trade places across CV folds while preserving the KKT correlation bound \(\alpha\).

\(\ell_1\) Polytope Geometry
α / α_max = 0.32
Vertex intersection pins \(\hat{\beta}_j = 0\) (\(A(\alpha)\)).

7. Methodology & References

Protocol

  • Splits: Persisted 80/20 (seed 42) in data/processed/<dataset>/split.json.
  • Leak-Free: Imputation, encoding, and scaling fit on train data and inside each CV fold only.
  • Penalty (\(\lambda \equiv \alpha\)): Ridge minimizes \(\|\mathbf{y}-\hat{\mathbf{y}}\|_2^2 + \alpha\|\boldsymbol{\beta}\|_2^2\); Lasso minimizes \(\frac{1}{2n}\|\mathbf{y}-\hat{\mathbf{y}}\|_2^2 + \alpha\|\boldsymbol{\beta}\|_1\).
  • Metrics: \(\mathrm{RMSE}=\sqrt{\frac{1}{n}\sum_{i=1}^n(y_i-\hat{y}_i)^2}\), \(\mathrm{MAE}=\frac{1}{n}\sum_{i=1}^n|y_i-\hat{y}_i|\), \(R^2=1-\frac{\sum_{i=1}^n(y_i-\hat{y}_i)^2}{\sum_{i=1}^n(y_i-\bar{y})^2}\) (plus LPM metrics for diabetes).
